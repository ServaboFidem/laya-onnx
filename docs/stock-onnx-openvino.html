Stock, ONNX and OpenVINO laya

Exporting to ONNX writes the model down as a fixed recipe that no longer needs PyTorch, which makes it lighter to deploy but barely faster. OpenVINO then compiles that same file for the CPU it runs on, and that is where the speed comes from. All three give the same answers. The plain-English walk-through is onnx-and-openvino-explained.md.

Latency is one question at each engine's default threads on a dual Xeon Gold 6148 (AVX-512), Windows 11. onnxruntime 1.30.0 and OpenVINO 2026.4.0 were measured in the same sitting with bench_latency (3 warm-up + 20 timed, median); PyTorch comes from the README's torch-vs-ONNX table, a separate sitting. With both engines held to 4 threads OpenVINO's lead over onnxruntime shrinks to 1.05× at one question (1.46× at 50). Sizes are on-disk package sizes. Parity is tests/test_onnx_local_e2e.py on real weights (318 checks). Full record: laya_onnx/README.md.
